# 验证范围

本页记录使用合成素材完成的工具检查与创意流程试跑。《催眠》的实际制作流程收录在 [README](../README.md)。

## 实际检查

| 项目 | 已验证内容 |
| --- | --- |
| 媒体读取 | 4 秒 PCM 音频的样本时长与媒体参数 |
| 抽帧 | 普通与非零起点合成视频的帧位置、源相对时间 |
| 无工具模式 | 无 FFmpeg 与 FFprobe 时的 WAV 降级、文本继续处理和视频限制报告 |
| 输入保护 | 原视频 SHA256 不变，超限输入不修改 |
| 输出保护 | 拒绝已有非空目录，限制帧数与总输出大小 |
| 失败处理 | 损坏媒体不产生虚假参数，超时给出明确错误，清理自建临时帧 |
| 技能配置 | YAML、相对引用与默认调用文本 |
| 安装 | 首次安装、旧版备份与替换，逐文件 SHA256 核对 |

媒体测试共 12 项，在具备 FFmpeg 与 FFprobe 的本地环境中全部通过。仓库提供同一测试代码，GitHub Actions 会重新运行；远程结果以实际运行记录为准。无媒体工具的环境会跳过相应测试，不应把跳过视为媒体能力通过。

## 创作行为试写

试写以原创歌词为素材，分别测试人物选择、空间规则和表演关系三种创意方向。选定模拟方向后扩写了场次剧本、制作分镜，并按模拟请求仅修订第二次副歌对应的场次。

这些是同一作者执行的人工场景检查，未进行独立模型评估。示例的音乐时间均待对齐；模拟请求不代表用户已经选定某个真实项目方向。

参考结构与节奏优先已经写入主入口、分析规范、创意开发、剧本模板和分镜规范。没有真实视频输入，尚未实测复杂作品的结构映射与节奏转译。

## 角色与背景图功能验证

实际使用内置 image_gen 传入一张合成角色正面图，生成并查看了正面、左侧面、背面的角色 sheet。可见造型与主要配色得到保留，包带在正背面遵循角色自身左右；原图未显示的侧背细节作为创作补全记录。

另将原创分镜用作场景参考，生成并查看了保留主要道具、空间结构与光色的无人背景。试跑记录标注了遮挡区域的重建与机位差异。

本次未修改本地媒体检查脚本，出图由实际图像工具调用与人工观察验证。没有实测真实人像、半身图补全、多角色归属或复杂场景视角转换，也没有另外生成同时采用这两项新资产的完整分镜序列。

## 限制

辅助脚本只提供元数据和少量代表帧，不自动识别歌曲结构、BPM、歌词、镜头边界或语义，也不承担出图。角色设定图、背景图与分镜图由宿主图像工具执行，图像生成与媒体分析分别验证。听觉与视觉分析依赖宿主可用能力，稀疏帧不能证明整片剪辑节奏或运镜。

合成测试未覆盖真实歌曲解释、真实参考 MV 分析、精准歌词对齐及跨宿主生成质量。Claude Code 实际调用尚未实机测试。

分镜图试跑实际生成并查看了三格测试页，核对了图片文件、布局、镜号和关键动作状态。部分道具与光色细节仍需精修，试跑覆盖的是出图与镜头映射。

生成的媒体、逐次检查报告和机器路径不纳入版本控制。运行测试会在 `validation/fixtures/` 创建忽略的合成文件；不安装模型或上传素材。
