# 验证范围

本项目将可执行工具检查与创意行为试写分别报告。测试素材为本地生成的合成视频、PCM 音频和原创歌词，没有使用真实歌曲或用户参考 MV。

## 实际检查

| 项目 | 已验证内容 |
| --- | --- |
| 媒体读取 | 4 秒 PCM 音频的样本时长与媒体参数 |
| 抽帧 | 普通与非零起点合成视频的帧位置、源相对时间 |
| 无工具模式 | 无 FFmpeg 与 FFprobe 时的 WAV 降级、文本继续处理和视频限制报告 |
| 输入保护 | 原视频 SHA256 不变，超限输入不修改 |
| 输出保护 | 拒绝已有非空目录，限制帧数与总输出大小 |
| 失败处理 | 损坏媒体不产生虚假参数，超时给出明确错误，清理自建临时帧 |
| 技能配置 | YAML、相对引用与默认调用文本 |
| 安装 | 首次安装、旧版备份与替换，逐文件 SHA256 核对 |

媒体测试共 12 项，在具备 FFmpeg 与 FFprobe 的本地环境中全部通过。仓库提供同一测试代码，GitHub Actions 会重新运行；远程结果以实际运行记录为准。无媒体工具的环境会跳过相应测试，不应把跳过视为媒体能力通过。

## 创作行为试写

原创歌词用于三个不同机制的创意方向试写：人物选择、空间规则、表演关系。随后按模拟选择扩写 [完整剧本](../examples/screenplay.md)，按模拟请求生成 [分镜](../examples/storyboard.md)，最后仅修订第二次副歌所对应场次，保留其他正文，见 [修订稿](../examples/screenplay-revision.md)。

这些是同一作者执行的人工场景检查，未进行独立模型评估。示例的音乐时间均待对齐；模拟请求不代表用户已经选定某个真实项目方向。

参考结构与节奏优先已经写入主入口、分析规范、创意开发、剧本模板和分镜规范。没有真实视频输入，尚未实测复杂作品的结构映射与节奏转译。

## 限制

辅助脚本只提供元数据和少量代表帧，不自动识别歌曲结构、BPM、歌词、镜头边界或语义。听觉与视觉分析依赖宿主可用能力，稀疏帧不能证明整片剪辑节奏或运镜。

真实歌曲解释、真实参考 MV 分析、精准歌词对齐和不同宿主的生成质量仍待验证。Claude Code 实际调用尚未实机测试。完成安装与格式检查也不代表所有宿主选择器已经实际加载。

生成的媒体、逐次检查报告和机器路径不纳入版本控制。运行测试会在 `validation/fixtures/` 创建忽略的合成文件；不安装模型或上传素材。
