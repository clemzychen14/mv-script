# 按需导演分镜

确认本轮剧本与版本，保留场次、角色、场景和段落 ID。用户明确授权从未确认稿直接分镜时可继续并注明版本；尚无故事时不能把临时镜头表称为“已确认剧本分镜”。

## 时间

可靠歌曲时长不等于可靠歌词对齐。分别注明总长、段落或歌词入点、拟定镜头起止的依据。只有顺序时，Start / End 填“待对齐”。

有歌曲总长但尚无剪辑时，可以提出设计起止，标为“设计时间，待与音频核对”，不称实测切点。秒数应可相加，不能超过总长或掩盖未覆盖区间。故事时间跳跃不应造成歌曲轴无意重叠。

有参考视频时，按结构映射承接其镜头疏密、画内动作节拍、停顿和转折，在 Transition / Editing 或 Production Notes 中标明相关参考段落或已核验镜头及来源时间。新时间依据目标歌曲安排，不能直接把参考时间当作目标切点。没有可靠连续证据时保留待核验标记。

## 字段

宽表可拆为对应编号的两张表，但保留有用字段。

| 字段 | 内容 |
| --- | --- |
| Shot ID | 唯一镜头号与 Scene ID |
| Start / End | 有依据起止或待对齐；设计时间另标 |
| Music / Lyrics | 段落、听觉变化或原文歌词与来源 |
| Scene / Character | 场景、角色、服装和道具状态 |
| Visual Action | 实际事件，动作起止状态 |
| Shot / Composition | 景别、构图、机位、空间关系 |
| Camera Movement | 服务叙事的固定、推拉、摇移、跟拍等 |
| Lighting / Color | 光源、明暗、色彩与变化 |
| Transition / Editing | 切点目的、匹配与承接条件 |
| Narrative Purpose | 使观众知道或感到的具体变化 |
| Production Notes | 连续性、难点、替代与待验证事项 |

## 检查

每镜头有独立信息或情绪作用，删掉只写“唯美”“震撼”而无事件的行。检查动作、视线、方向、服装、道具与光色。长度服务观看与音乐，不采用每 15 秒九镜头或每重拍一切的硬规则。明确实际时间覆盖与未对齐部分。用户要求分镜图时，按 [分镜图生成规范](storyboard-images.md) 实际出图并保留镜头对应；仅要求镜头表时停在文字分镜。不生成最终视频或提交视频任务。
