# 分镜图生成

## 何时执行

用户明确要求分镜图、故事板图片、逐镜画面或修改现有分镜图时执行。仅要求概念、剧本或文字分镜时，不自动出图。采用已确认稿；用户明确指定未确认稿并要求直接出图时按该授权工作，注明版本即可。已有镜头内容足够清楚时，不再为同一范围反复要求确认。

没有镜头设计但已要求出图时，先从当前故事补齐简短的镜头计划。只就会改变故事或角色身份的核心歧义询问，不要求用户先走完整套提案。用户已要求全部图片时连续完成；用户只要预览时生成指定数量或一小页即可。

## 图像工具与参考

优先使用宿主实际提供的内置图像生成或编辑工具，例如 `image_gen`；有配套 imagegen 技能时遵循它的调用、保存和检查方法。无需用户另配 API Key。其他宿主使用其可用的等效工具；工具不可用时交付镜头描述和限制，不声称图片已生成，也不自动切换到需要密钥的外部服务。

真正生成可查看的图片，不用 SVG 占位框、文字卡片或仅提示词替代。处理已有分镜图的修改时，先实际查看目标图；只修改指定内容，保留其他角色、服装、道具、构图与风格。对用户提供的角色图和美术图明确标注用途，读取后再交给生成工具。后续图片可引用已选定图像保持一致性，不能默认为生成结果完全复现参考身份。

图像工具可能是宿主的托管服务，本功能不承诺全离线出图。本地媒体检查仍只读本地文件；出图只提供本轮需要的文字和图片参考，不额外上传整段音视频。

如已生成角色设定图与背景图，先读取 `assets/index.md` 中采用的版本，并实际将图片传给出图工具。角色图提供外观与服装锚点，背景图提供场景结构与光色锚点。缺少设定图时可直接使用原参考，不强制先生成完整资产。需要补图时按 [角色与背景图规范](visual-assets.md) 执行。

## 从镜头表到画面

先固定角色外观锚点、服装状态、道具状态、场景方向与色光。没有角色图片时，以已采用的文字设定创作外观，并标为新增设定。不同镜头的变化须由场次与动作支持，不随意改变角色或空间。

为每镜头记录 Shot ID、可见人物和动作时刻、景别、机位、构图、场景、光色、连续性要求和参考图用途。动作以一个关键瞬间表现；需要表达动作前后时另设关键画面并标注，不能用静态画面声称实现运镜或精确音乐同步。

优先遵循用户的风格与画幅要求，其次参考实际读取的视觉材料。没有风格要求时采用清楚易读的电影分镜草图。不要强制转成某种写实或动漫风格。

用户要单镜图时逐镜生成；要多格故事板时按场次或叙事段落分页。未指定排版时，每页约 4 至 6 格可作为可读性建议，实际数量取决于内容，少量镜头直接用少量格数，不补空格凑九宫格。保持各格画幅和观看顺序清楚。

提示词写清页面布局与顺序、每格的 Shot ID 和具体画面，再写共享的角色与环境约束。画面内尽量只保留简短镜头编号，长中文说明与时间信息放在外部索引，降低文字错误与画面拥挤。

## 检查与修订

实际查看输出，核对镜头数与顺序、角色辨识特征、服装配饰、道具、动作方向、机位、光色和格子裁切。对照文字镜头表，避免缺镜、重复画面或用美术氛围掩盖叙事事件。生成图的外观一致性与空间逻辑需要逐张检查，不能用提示词相同作为通过证据。

发现问题时优先对指定画面进行局部编辑或定向重试。相同失败最多定向重试两次，仍无法满足时说明具体问题并保留已完成图片，不无限消耗生成次数。后续用户明确要求继续时再按新指示推进。版式或角色变化会影响已完成关联镜头时，做最小同步修订并说明。

## 保存与交付

按用户目录保存；否则放入本项目 `mv_project/storyboard_images/`。将宿主工具产生的实际文件复制或移动到项目目录，不只留下宿主缓存路径。采用稳定镜头号或页面号，例如 `S03_01.png` 或 `page_01.png`，新版本用独立文件名保留旧稿。

建立 `index.md`，记录实际图片路径、对应镜头、采用的剧本版本、生成或编辑说明与检查结果。只登记实际存在的图片；未生成、失败或待修订项独立标明。保留最终图像描述或提示词，方便后续复现和修改。

在回复中直接展示本轮图片，并提供项目文件路径。单页多格图与逐镜图片分别说明，生成的是静态分镜图，不代表镜头运动、唇形、音画同步或最终视频已经验证。
