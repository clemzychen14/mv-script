# 从参考图片生成角色设定图与背景图

## 输入与执行范围

不要求用户先提供精修 character sheet。单张可读照片、插画、半身图、局部细节或多张零散参考均可起步。只提供文字也可以做原创设定图，但要明确外观是创作新增。素材可逐步补齐，不把三视图或背景全景作为前期创作的准入条件。

仅在用户要求角色设定图、角色视图、背景图、场景设计图或明确要求补齐相关视觉资产时生成。仅分析原图、写设定卡、提概念或生成分镜图，不自动批量制作全部缺失资产；已有图片足够支持本轮工作时直接使用。

只要求角色图就只生成角色图，只要求背景就只生成背景；要求整套时按授权完成，不逐张重复确认。预览请求限制在预览范围。身份、参考归属或核心造型的歧义会改变结果时提出具体问题，其余缺失可做有标记的合理补全。

## 共用图像执行

先实际查看每张参考图，标注角色身份、服装、场景结构、光色或风格等用途。原文件保留不动，生成图用独立文件名。区分参考图、编辑目标与已采用结果，按工具支持的方式传入图片，不只描述文件名。

优先使用宿主内置图像生成或编辑工具，遵循其规范；有 imagegen 技能时配合使用。无需单独配置 API Key，不自动改走需要密钥的外部接口。没有图像工具时交付设定和描述，明确实际未出图。

图像生成可能由托管服务提供，不承诺全离线。只提供本轮必要的文字和图片参考，不额外上传音视频。不用占位轮廓或提示词文件代替实际设定图。

## 角色 character sheet

先分清同一角色、换装状态和不同人物。不确定的图分开记录；多图冲突时采用用户指定的身份与造型锚点，不任意合并人脸或服饰。不从外观推断敏感属性。用户要求保持原角色时，不擅自美化、改脸、换服装或改变绘画风格。

简短记录可见事实、用户锁定项与创作补全。发型、面部概括、身形、剪裁、主要配色和配饰要在各视角可辨。背面、未显示鞋履或遮挡细节可以补画，但不能声称从正面图恢复出了真实设计。

默认按用途制作一页清楚的全身正面、侧面和背面视图；用户只要半身、表情、服装或某一视角时遵循其范围。三视图保持相近比例、统一站姿、同一角色与服装。非对称发型、包带和饰品写明角色自身左右，避免把画面左右误当人物左右。特写按用途增补，不强制填满所有栏位。

背景简洁，不让视图互相遮挡、裁掉头顶与鞋履或塞入大量文字。用简短视角标签，长设定和补全说明放外部设定卡。统一比例是绘图目标，不是精确测量或三维建模验证。

## 场景与背景图

区分保留原场景的空背景、根据参考重新设计的场景，以及同场景其他机位或光照状态。按用户目的工作；只要求从画面生成背景且未另指定时，可先做保留可见空间与风格的无人背景，说明遮挡区域属于重建。

提取主结构、出入口、固定道具、材质、色彩、光源和可见机位。保留锁定的窗门、楼梯、道路方向及建筑特征。人物或前景遮挡处的墙面、地面与物体位置是创作补全，不称为原景精确复原。

背景以可供后续镜头构图的画面为主，按需要保留人物站位、前中后景和可辨地标。不在无人背景中加入人物、字幕或角色设定格。只有要求场景设定页时才组织多个机位，不机械套用角色三视图排版。

同场景昼夜或不同机位保留固定空间与道具关系。用简短布局说明记录已采用方位，不凭几幅互相矛盾的图声称空间一致。只借鉴光色材质而重做布局时，明确属于新场景设计。

## 检查与版本

实际查看输出。角色检查辨识特征、服装配饰、非对称细节、各视角比例及完整性；背景检查结构、方向、固定物、光色、人物残留和不应出现的文字。静态多视图不保证三维一致，也不能保证之后所有镜头的身份完全稳定。

偏差只改对应视角、角色或区域，保留其他已采用内容。相同问题最多两次定向重试，仍有问题就标注限制及完成范围，不无限生成。不覆盖用户原图，不把试稿自动标成用户已确认。

## 保存与分镜衔接

默认写入项目 `mv_project/assets/characters/` 与 `mv_project/assets/scenes/`；用户指定位置时遵循要求。文件名含 ID 和版本，例如 `C01_sheet_v01.png`、`E01_background_v01.png`。实际文件复制或移动到项目，不只引用宿主缓存。

`assets/index.md` 记录原图用途、实际图片路径、ID、版本、可见锚点、创作补全、检查结果及试稿或采用状态。关联同版本的 `character_bible.md` 或 `scene_bible.md`，只创建当前需要的文件。保留最终图像描述以便修改。

后续分镜先读取采用版本，再把实际图像传给工具：角色 sheet 约束外貌服装，背景图约束空间光色。可改变姿势、表情和机位，但保留锁定设计；没有 sheet 时仍可使用原参考。资产修改后只检查受影响镜头，不重写全部剧本。

交付实际图片、项目路径和必要的补全说明。不要把视觉资产生成称为最终视频制作完成。
