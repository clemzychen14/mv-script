# 视频生成工作包

从已采用的逐片段提示词和片段索引开始。先核对目标模型、输入模式、剪辑顺序、原镜号与采用的素材版本。用户要全套时覆盖所有片段，用户指定范围时按该范围制作。已有完整提示词时直接打包。

## 整理提示词和输入

每个片段单独存放可复制的 `prompt.txt`，保留采用稿的语言、换行、模型字段、参考标签和时间格式。配套 `inputs.md` 写明模型及版本、输入模式、生成时长、画幅、音频处理和可核验的界面参数。说明生成时长和 MV 时间线上的位置，给尚未核验的时间保留标记。

在 `inputs.md` 建立标签与文件的对应关系。每条注明模型里的实际输入槽位或标签、包内相对路径及用途，例如首帧、尾帧、角色参考、场景参考、运镜参考视频或口型参考音频。后期叠加的原曲在说明里写明用途，需要随包移交时放入 `edit/`。按采用的模型和模式选择实际输入。模型需要独立首尾帧时，用对应的单镜图片作为输入，多格分镜页可随包供查看。

复制当前任务用到的实际图像、视频和音频文件到 `assets/`。保留原素材与文件版本。多片段共用的同一素材随包带一份，从各片段引用同一路径。同名不同素材加素材编号区分。引用写为可随包移动的相对路径，确认目标实际位于包内。有采用的 [静止帧试剪](still-frame-edit.md) 时，把该版镜号时间表放进 `edit/` 并在索引链接。分镜表、试剪预览和后期原曲按交接需要随包提供。

## 包内布局

保持片段编号和顺序与已有索引一致。以下是包含两个片段的目录示例，目录与 ZIP 中只放本轮实际交付的文件。

```text
generation_package_v01/
  index.md
  clips/
    V01/
      prompt.txt
      inputs.md
    V02/
      prompt.txt
      inputs.md
  assets/
    C01_sheet_v01.png
    V01_start.png
    V02_start.png
  edit/
    shot_timing.md
```

首页 `index.md` 写明项目、包版本和使用方式。让接手人解包后按剪辑顺序打开片段，复制提示词，并根据输入表选择文件和设置参数。索引列出各片段的原镜号、目标模型与模式、时长、提示词链接、输入表链接及待补项。

## 核对并交付

在压缩前逐段核对镜号覆盖、提示词参考标签、输入模式与实际文件。确认所有必需输入可读，路径能在移动后的目录解析。项目所需规格已核验时检查对应的格式、画幅和时长。缺少必要输入时，先从已采用的素材或现成版本补齐。仍有缺项就交付可完成的内容，在索引和对应输入表中标明受影响片段、缺项和下一步所需材料，并把该片段的准备状态标为待补齐。

将整理好的单一工作包目录做成 ZIP，保存到用户指定位置，或作为 `generation_package_v01.zip` 保存到项目根目录。使用现有归档工具或 Python 标准库 `zipfile`，核对归档可读、目录与文件齐全、相对引用可用。用户要求目录形式时交付同结构目录。修订时更新受影响的片段与素材版本，重新核对索引并保存修订版。交付包路径、覆盖的片段和待办项，视频制作由下一环节接手。
